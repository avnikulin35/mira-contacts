Mira contacts — Privacy Policy

Effective date: 15 November 2026.

What data is accessed

With the owner's consent, Mira contacts uses the Google People API with the single scope https://www.googleapis.com/auth/contacts.readonly. It reads the owner's Google Contacts (names, phone numbers, email addresses, companies) only to answer the owner's own request, for example "what is this person's phone number". It cannot create, change or delete contacts.

Where data is stored

  • The OAuth access token is stored locally on the owner's computer, in a file readable only by the assistant's user account.
  • Contacts are not copied into any database. They are read from Google on demand, when the owner asks, and are not kept after the answer is given.
  • There are no analytics, trackers or advertising in the app or on this website.

Sharing

Contact data is not sold, shared with or transferred to third parties, and is not used for advertising. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

Open myaccount.google.com/permissions, choose "Mira contacts" and remove access. After that the app can no longer read contacts. The owner can also ask for the local token file to be deleted.

Contact

Questions about this policy: through the owner of the assistant, or via GitHub issues of this repository.

Mira contacts — Политика конфиденциальности

Дата вступления в силу: 15 ноября 2026 г.

Какие данные читаются

С согласия владельца Mira contacts обращается к Google People API с единственным разрешением https://www.googleapis.com/auth/contacts.readonly. Приложение читает Google Контакты владельца (имена, телефоны, адреса почты, компании) только чтобы ответить на запрос самого владельца, например «какой телефон у этого человека». Создавать, изменять и удалять контакты оно не может.

Где хранятся данные

  • Токен доступа OAuth хранится локально на компьютере владельца, в файле, доступном только учётной записи ассистента.
  • Контакты не копируются ни в какую базу данных. Они читаются из Google по запросу владельца и не сохраняются после ответа.
  • В приложении и на этом сайте нет аналитики, трекеров и рекламы.

Передача данных

Данные контактов не продаются, не передаются третьим лицам и не используются для рекламы. Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Откройте myaccount.google.com/permissions, выберите «Mira contacts» и удалите доступ. После этого приложение больше не сможет читать контакты. Владелец также может попросить удалить локальный файл токена.

Контакт

Вопросы по этой политике — через владельца ассистента или через GitHub issues этого репозитория.
